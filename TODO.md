# Remaining verification

All terms in the two initial tables now have pages, and all explicitly quoted verses have been checked in the cited e-texts. The work is not a completed philological edition.

- Complete noun derivations remain unchecked wherever each term page says so. A checked root entry is not a checked derivation.
- jīva, śruti and deha still need defining passages in their relevant primary texts. Citta now has supplementary Yoga evidence; kāya has a Pāṇinian derivation with the body sense. A missing defining quotation is recorded, not replaced from memory.
- viṣaya requires a resolved grammatical derivation; sākṣin now has a checked Pāṇini/Kāśikā account, with the deeper formation of sākṣāt still open; ātman’s historical etymology and the Greek/Indo-European claims need historical-linguistic evidence.
- āma has an explicit supplementary definition in Aṣṭāṅgahṛdaya 13.25–26; an equivalent defining passage in the originally requested three-text set remains unverified.
- Reflection is checked in Vācaspati’s Yoga commentary; its extension to a biographical/mechanical copy remains an analogy. The root Kārikā alone does not state it.
- Collation with the local Sanskrit scanned editions and their variants has not been performed.
